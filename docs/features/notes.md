# Notes

The **Notes** page holds Markdown notes. It needs the **Take notes** permission.

- **New note** starts a note. It saves by itself as you type once it has a title (3 to 48 characters) and some content (up to 50,000 characters).
- Switch between **Edit**, **Split** and **Preview**. Markdown is rendered without raw HTML, and links only work with `http`, `https`, `mailto` and relative addresses.
- **Make public** in a note's menu gives it a public page (`/note/<id>`), and **Copy public link** copies it. Private notes are only visible to you.
- **Copy content** copies the Markdown.
- Deleted notes go to the [trash](trash.md).

Public notes get a [link preview](../link-previews.md) on Discord and other apps. In [Fileship for Windows](../desktop.md), Fileship Harbor shows your notes as `.md` files in File Explorer, and saving one updates the note. Text shared to Fileship from an Android phone is saved as a note (see [Fileship on your phone](../mobile.md)).
