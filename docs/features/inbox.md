# Inbox

The inbox is a page where anyone with the link can send you files, without an account. Set it up in **Settings → Inbox**.

1. Turn on **Enable inbox**.
2. Copy the **Inbox link** (`/inbox/<link>`). You can change the last part and **Save link**.
3. Optionally set a **Password** and **Save password**. Leave it empty to let anyone send files.

Files people send land in your **Inbox** folder (**Open inbox folder**) and count toward your storage limit. Uploads stop when your storage is full. Each sender is limited to 120 uploads a minute.

In [Fileship for Windows](../desktop.md), right click a Harbor folder to copy its inbox link. [Webhooks](../webhooks.md) send `file.uploaded` for files that arrive through the inbox too.
