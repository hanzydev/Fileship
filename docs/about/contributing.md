# Contributing

Fileship is open source, and contributions are welcome: bug reports, fixes, features and translations.

- **[Contributing guide](../../CONTRIBUTING.md):** how to set up a development environment (Node.js, pnpm, PostgreSQL 18 or Docker), run the dashboard and send a pull request.
- **[AGENTS.md](../../AGENTS.md):** the architecture, conventions and rules of the repository, for people and AI coding agents.
- **[I18N.md](../../I18N.md):** how Fileship is translated into its 12 languages, with style guides and glossaries.
- **Bugs and ideas:** open an issue on [GitHub](https://github.com/hanzydev/Fileship/issues). For problems with your own server, check [Troubleshooting](../troubleshooting/index.md) first.
- **Security problems:** see [Security](security.md); please don't report them in public issues.

These docs live in the repository's `docs/` folder. Spotted a mistake? Edit the page on GitHub and open a pull request.
